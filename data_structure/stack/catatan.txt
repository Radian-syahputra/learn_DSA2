*** STRUKTUR DATA STACK ***

* Konsep -> 
    Stack Mengunakan Konsep LIFO (Last In First Out) yang dimana elemen terakhir yang dimasukkan adalah yang pertama kali dikeluarkan. 
    seperti tumpukan buku

    Struktur Last In, First Out — cuma bisa diakses dari satu ujung (top). Seperti tumpukan piring: yang terakhir ditaruh, itu yang pertama diambil.

    - push = taruh di atas
    - pop = ambil & hapus dari atas
    - peek = lihat atas, tanpa hapus

* Operasi ->
    Push: Menambahkan Elemen Baru di tumpukan atas ke dalam stack.
    Pop: Mengeluarkan elemen di tumpukan atas dari stack.
    Peek: Melihat elemen teratas tanpa mengeluarkannya.
    IsEmpty: Memeriksa apakah stack kosong.
    IsFull: Memeriksa apakah stack penuh.

* Visualisasi ->

    Top → │ Citra │  ← terakhir masuk, pertama keluar
          │  Ani  │
          │ Budi  │  ← pertama masuk, terakhir keluar
          └───────┘

* Cara Kerja *
    push:
    node_baru.next = self.top   ← sambung ke top lama
    self.top = node_baru          ← pindahkan top
    
    pop:
    node_teratas = self.top
    self.top = node_teratas.next  ← pindahkan top ke next-nya
    return node_teratas.data
    

* Contoh ->

    # Contoh Implementasi Stack Versi List
    class Stack :
        def __init__(self) -> None:
            self.data : list[int] = []
    
        def isEmpty(self) -> bool :
            if len(self.data) == 0 :
                return True
            return False
    
        def push(self, item: int) -> None:
            self.data.append(item)
    
        def pop(self) -> int :
            if self.isEmpty():
                raise IndexError("pop from empty stack")
            return self.data.pop()
    
        def peek(self) -> int :
            if self.isEmpty():
                raise IndexError("peek from empty stack")
            return self.data[-1]
